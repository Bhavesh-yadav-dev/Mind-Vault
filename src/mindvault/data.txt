NoteNest is a personal knowledge app created by Alex Morgan. It was started in January 2025 as a side project. The app stores notes, links, and short documents in one place. NoteNest runs fully offline on the user's laptop. It uses Ollama to run local language models. The embedding model is nomic-embed-text. The chat model is qwen3 with four billion parameters. Notes are split into chunks of five sentences with an overlap of two sentences. Each chunk is converted into a vector and stored in memory. When a user asks a question, the question is also converted into a vector. The app finds the three most similar chunks using cosine similarity. Those chunks are sent to the language model as context. The model is told to answer only from that context. If the answer is not found, it replies that it does not know.

Alex lives in Riverton, a fictional city in the country of Eldoria. Riverton is famous for the Crystal Gorge. The Silver River flows through the gorge there. Visitors can take boat rides between the white limestone cliffs. The Thunder Falls are located nearby. The best time to visit is between October and March. Summers in the region are very hot.

The NoteNest roadmap has three planned features. The first is PDF import, planned for March 2025. The second is a tagging system for organizing notes. The third is a mobile app for Android. The project is written in Python. It uses numpy for vector math and requests for talking to Ollama. The source code is stored in a folder called src.
